# StelligenOS 项目身份

StelligenOS 是 biotechnology asset operating system 的**实现仓库**，不是数据库或结果仓库。正式定义见 [架构契约](../docs/architecture/contract.zh-CN.md) 与 [仓库说明](../README.md)。

## 当前交付边界

- 保存架构契约、Prompt、Schema、脚本、代码、参考文档与少量受控示例。
- 数据采集、处理、分析与存储发生在仓库外部工作区。
- 本 UDE 目录只索引理解、设计和执行状态；不改变既有正式契约的权威路径。

## 决策与审批

仓库变更遵循 [AGENTS.md](../AGENTS.md) 和 [分阶段 PR 审核协议](../docs/protocols/CHATGPT_CODEX_PHASE_GATE_PROTOCOL.zh-CN.md)。UDE 记录中的建议、待审内容和版本空缺均不构成新的架构授权。
