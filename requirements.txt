#

# `enum.StrEnum`, added in 3.11. CI runs 3.11 and 3.12 so that floor is enforced
# rather than merely asserted.

# repository: no test imports those modules, nothing here executes them, and
# `src/repository/external_runtime.py` is contract-only by design. Installing

# They belong to the external workspace that implements `ExternalRuntimePort`.

# Non-Python tool dependency
