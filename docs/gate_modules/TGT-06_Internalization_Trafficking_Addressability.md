## Three headline conclusions (审核方原话, frozen verbatim)

> **1. Internalization is configuration-specific, not a target-intrinsic
> constant.** One qualifying disease-relevant antibody / epitope configuration
> with productive antibody-induced internalization and lysosomal delivery is
> sufficient DIRECT existence proof for addressability; failure of one
> configuration is only configuration-level opposing evidence and can never
> establish target-wide non-internalization.

> **2. DIRECT productive-addressability authority requires an auditable
> integrated observation** tying antibody-induced internalization and lysosomal
> delivery to the same antibody / epitope configuration in a disease-relevant
> context. Surface localization, receptor-family inference, constitutive
> endocytosis, internalization without confirmed lysosomal delivery, non-CRC
> internalization and successful same-target ADC precedent remain lower-ceiling
> evidence and may not be combined across unrelated observations or
> configurations to synthesize DIRECT.

> **3. A target-wide surface-static potential fatal pattern requires
> productive-internalization / trafficking failure across multiple independent
> qualified antibody / epitope configurations** and no qualifying productive
> DIRECT existence proof in the completed landscape. The machine may surface only
> `POTENTIAL_FATAL_PATTERN`; it never decides fatality, ADC efficacy, KILL, HOLD
> or a Candidate-level Decision.

**Core chain.** qualified disease-relevant context × antibody / epitope
configuration identity × assay validation × audited
internalization-evidence-search completion → Gate-neutral empirical
internalization / trafficking observations → frozen rung → a
**highest-qualifying-rung** grading authority under an **existence-proof**
aggregation truth table (one qualifying `DIRECT` productive configuration is
`POSITIVE / DIRECT`; a qualifying `INDIRECT_STRONG` addressability landscape with
no `DIRECT` is `POSITIVE / INDIRECT_STRONG`; a single `DIRECT`-quality failure is
`INCONCLUSIVE / DIRECT`, never `NEGATIVE`) → aggregate addressability Direction ×
Strength → optional multiple-independent-configuration-failure `fatal_review` →
human review / GateSet policy. It never becomes: surface expression → assumed
internalization; receptor-family membership → assumed internalization; one
non-internalizing configuration → target-wide non-internalization; a measured
%-internalized value → an invented ADC-effective internalization rate; a `DIRECT`
existence proof stitched from unrelated observations; a `NEGATIVE` addressability
call → `KILL`.

## Normalized internalization observation & the typed completion (conceptual shape, PR E14 freezes it)

A **normalized internalization observation** (provider fact only — no rung, no
direction, no pass / fail):

`observation_id` · `target_identity` · `context_key` · `landscape_as_of` ·
`observation_kind` ∈ {`ANTIBODY_CONFIGURATION_INTERNALIZATION_TRAFFICKING`,
`ANTIBODY_CONFIGURATION_INTERNALIZATION_ONLY`, `TRAFFICKING_OR_RECYCLING_ONLY`,
`SAME_TARGET_ADC_DELIVERY_PRECEDENT`,
`CONSTITUTIVE_ENDOCYTOSIS_OR_RECEPTOR_BIOLOGY`,
`RECEPTOR_FAMILY_MEMBERSHIP_INFERENCE`, `SURFACE_LOCALIZATION_ONLY_INFERENCE`,
`SEARCH_COMPLETION_AUDIT`} · `internalization_outcome` ∈
{`PRODUCTIVE_INTERNALIZATION_WITH_LYSOSOMAL_DELIVERY`,
`INTERNALIZATION_OBSERVED_LYSOSOMAL_DELIVERY_UNRESOLVED`,
`FAILS_PRODUCTIVE_INTERNALIZATION_OR_TRAFFICKING`, `MIXED_OR_UNRESOLVED`,
`NOT_ESTABLISHED`} + `internalization_outcome_basis` (a CLOSED typed classifier —
**never** computed from a number) · `assay_method` (a factual type — **open
set**, not a closed assay whitelist) · `assay_validation_status` ∈ {`QUALIFIED`,
`NOT_ESTABLISHED`} + `assay_validation_basis` (**closed predicate** — DIRECT
requires `QUALIFIED` + an auditable basis **and** a non-empty `assay_method`;
`QUALIFIED` is not a positive addressability conclusion) · `crc_specific` ·
`surface_context_class` ∈ {`CRC_MALIGNANT_CELLS`, `WELL_MATCHED_CRC_MODEL`,
`NON_CRC_CONTEXT`, `UNRESOLVED`} + `surface_context_basis` ·
`context_adequacy_status` ∈ {`QUALIFIED`, `NOT_ESTABLISHED`} +
`context_adequacy_basis` · `reproducibility_status` ∈ {`QUALIFIED`,
`NOT_ESTABLISHED`} + `reproducibility_basis` ·
`declared_multi_configuration_analysis` (bool) · `internalization_configuration_id`
/ `internalization_configuration_ids` (a declared multi-configuration analysis; a
**local** evidence-context namespace, never the canonical Instantiation
`context_id` `CTX-CRC-REFRACTORY-MCRC`) · `configuration_identity_basis` ·
`antibody_identity` / `epitope_identity_or_region` / `affinity_context` /
`conjugation_context` (OPEN factual strings — **not** all four required) · an
optional source-reported numeric assay fact inside the neutral claim (never
compared to a threshold; **no dedicated typed raw field, no symmetric raw-value
reuse-parity branch**) · `source_id` + source metadata + `retrieved_at`.

The typed **`InternalizationEvidenceCompletion`** (a run-level machine record,
**not** a seventh core object): `attempted` · `landscape_as_of` · `search_scope`
· `sources_searched` · `public_internalization_search_complete` (== `all` of the
next four) · `antibody_configuration_internalization_search_complete` ·
`productive_trafficking_search_complete` ·
`same_target_adc_functional_delivery_search_complete` ·
`receptor_endocytosis_and_inference_search_complete` · `unresolved_items` ·
`qualifying_direct_configuration_ids` · `audit_observation_id`. **Mandatory
search = search-completion axes, not evidence prerequisites and not grading
axes** — a component *searched / exhausted with zero qualifying records* still
counts complete; it exists only so the Module cannot find one pretty
internalization movie, stop searching the other axes, and cherry-pick a
Direction. **Exactly ONE qualifying configuration set** —
`qualifying_direct_configuration_ids` (the LOCAL antibody / epitope configuration
identities of the observations classified qualifying `DIRECT`-rung — productive
or DIRECT-quality failure). **There is deliberately NO
`qualifying_indirect_configuration_ids` set** (a constitutive-endocytosis /
receptor-biology or same-target-ADC precedent observation does not inherently

IS inventory audit). The `SEARCH_COMPLETION_AUDIT` observation carries a
structured snapshot of this record locking the qualifying configuration set; the
snapshot fields are exact-reuse parity keys and a drift / missing / dedup-lost
snapshot, or a drift in the qualifying configuration set, is a HARD run-level
integrity failure in PR E14.
