## Three headline conclusions (审核方原话, frozen verbatim)

> **1. A measurable soluble form is not the same thing as a material antigen
> sink.** Quantified circulating soluble target, documented sheddase processing
> or a validated secreted isoform may support the presence of a soluble-antigen
> sink-liability class at INDIRECT_STRONG, but materiality requires DIRECT
> evidence from a documented same-target PK / PD sink effect or a qualified
> quantitative TMDD analysis; a concentration value, including a low or
> below-assay-limit value, is never converted by the Module into a universal
> material-sink threshold.

> **2. Soluble-antigen materiality is exposure-context dependent.** DIRECT
> observations are bound to an auditable local sink-exposure context; one clean
> DIRECT material-sink context is sufficient for POSITIVE / DIRECT, while a
> canonical NEGATIVE / DIRECT requires a qualified intended-ADC TMDD analysis
> demonstrating no material soluble sink. Opposite DIRECT conclusions are
> CONFLICTING only when they refer to the same sink-exposure context; the machine
> has no conflict resolver in v1.

> **3. The TGT-07 potential-fatal signal is a strict subset of POSITIVE /
> DIRECT, not a convergence rule.** One qualifying DIRECT observation may surface
> `POTENTIAL_FATAL_PATTERN` when soluble antigen is documented or quantitatively
> modelled to materially compromise the clinically achievable exposure of a
> target-directed antibody. Clinical and TMDD evidence are alternative qualified
> source paths; the machine never decides fatality, KILL, HOLD, therapeutic
> efficacy or the Candidate-level consequence.

**Core chain.** qualified soluble-antigen evidence context × sink-exposure
context identity × analysis validation × audited
soluble-antigen-evidence-search completion → Gate-neutral empirical
soluble-antigen / shedding / PK observations → frozen rung → a
**highest-qualifying-rung** grading authority under an **exposure-context**
aggregation truth table (one CLEAN material-sink `DIRECT` sink-exposure context
is `POSITIVE / DIRECT`; a qualifying `INDIRECT_STRONG` soluble-antigen landscape
with no `DIRECT` is `POSITIVE / INDIRECT_STRONG`; a single DIRECT-quality
`MIXED_OR_UNRESOLVED` analysis is `INCONCLUSIVE / DIRECT`; a below-assay-limit
quantitation is `CONTEXTUAL` and propagates no Direction) → aggregate
sink-liability Direction × Strength → optional single-observation `fatal_review`
→ human review / GateSet policy. It never becomes: a measured circulating
soluble-antigen concentration → a material antigen sink; a below-assay-limit
value → proof of no soluble form; absence of a predicted cleavage site → no
shedding; a same-target therapeutic with no reported PK sink → `NEGATIVE /
DIRECT`; a documented or modelled sink → `KILL`.

## Normalized soluble-antigen observation & the typed completion (conceptual shape, PR E16 freezes it)

A **normalized soluble-antigen observation** (provider fact only — no rung, no
direction, no pass / fail):

`observation_id` · `target_identity` · `context_key` · `landscape_as_of` ·
`observation_kind` ∈ {`CLINICAL_ANTIGEN_SINK_PK_EFFECT`,
`SOLUBLE_ANTIGEN_TMDD_ANALYSIS`, `SOLUBLE_ANTIGEN_QUANTITATION`,
`SHEDDASE_SUBSTRATE_STATUS`, `SECRETED_ISOFORM`,
`PREDICTED_CLEAVAGE_SITE_INFERENCE`, `FAMILY_ANALOGY_SHEDDING_INFERENCE`,
`SEARCH_COMPLETION_AUDIT`} · `circulating_soluble_target_status` ∈
{`QUANTIFIED_PRESENT`, `BELOW_DETECTION_OR_QUANTITATION_LIMIT`,
`MIXED_OR_UNRESOLVED`, `NOT_ESTABLISHED`} + `circulating_soluble_target_basis` ·
`cohort_class` ∈ {`CRC_PATIENT_SERUM`, `HEALTHY_DONOR_SERUM`,
`SAME_TARGET_THERAPEUTIC_PK`, `WELL_MATCHED_MODEL`, `NON_CRC_CONTEXT`,
`UNRESOLVED`} + `cohort_class_basis` · `sink_materiality_outcome` ∈
{`MATERIAL_SOLUBLE_SINK_WITH_CLINICAL_EXPOSURE_COMPROMISE`,
`MATERIAL_SOLUBLE_SINK_WITHOUT_ESTABLISHED_CLINICAL_EXPOSURE_COMPROMISE`,
`NO_MATERIAL_SOLUBLE_SINK`, `MIXED_OR_UNRESOLVED`, `NOT_ESTABLISHED`} +
`sink_materiality_outcome_basis` (a CLOSED typed classifier — **never** computed
from a number) · `analysis_method` (a factual type — **open set**, not a closed
method whitelist) · `analysis_validation_status` ∈ {`QUALIFIED`,
`NOT_ESTABLISHED`} + `analysis_validation_basis` (**closed predicate** — DIRECT
requires `QUALIFIED` + an auditable basis **and** a non-empty `analysis_method`;
`QUALIFIED` is not a positive sink-liability conclusion) ·
`tmdd_input_adequacy_status` ∈ {`QUALIFIED`, `NOT_ESTABLISHED`} +
`tmdd_input_adequacy_basis` (`QUALIFIED` iff concentration / turnover / binding
affinity / dose-exposure assumptions are all included or explicitly, auditably
handled — E16 does not semantic-parse prose) · `same_target_therapeutic_match_status`
∈ {`QUALIFIED`, `NOT_ESTABLISHED`} + `same_target_therapeutic_match_basis` +
`same_target_therapeutic_ref` · `soluble_antigen_attribution_status` ∈
{`QUALIFIED`, `NOT_ESTABLISHED`} + `soluble_antigen_attribution_basis` ·
`exposure_scenario_class` ∈ {`INTENDED_ADC_EXPOSURE`,
`SAME_TARGET_THERAPEUTIC_ANALOGUE`, `UNRESOLVED`} + `exposure_scenario_basis` ·
`reproducibility_status` ∈ {`QUALIFIED`, `NOT_ESTABLISHED`} +
`reproducibility_basis` (the clinical fatal-path per-observation gate) ·
`sink_exposure_context_id` (a **single local string** — a therapeutic format ×
dose / exposure × affinity × patient / model descriptor; a **local**
evidence-context namespace, never the canonical Instantiation `context_id`
`CTX-CRC-REFRACTORY-MCRC`; REQUIRED on a qualifying `DIRECT` observation, `""`
otherwise; **no `declared_multi` / `IDENTIFIED_MULTI` / third-state, no
set-projection helper**) · `sink_exposure_context_basis` · an optional
source-reported numeric fact inside the neutral claim (never compared to a
threshold; **no dedicated typed raw field, no symmetric raw-value reuse-parity
branch**) · `source_id` + source metadata + `retrieved_at`.

The typed **`SolubleAntigenEvidenceCompletion`** (a run-level machine record,
**not** a seventh core object): `attempted` · `landscape_as_of` · `search_scope`
· `sources_searched` · `public_soluble_antigen_search_complete` (== `all` of the
next four) · `soluble_antigen_quantitation_search_complete` (true only when
**both** the CRC-patient and the healthy-donor serum / plasma search subspaces
are searched / exhausted) · `sheddase_processing_search_complete` ·
`secreted_isoform_search_complete` · `same_target_pk_pd_or_tmdd_search_complete`
(explicitly covers clinical PK / PD **and** target-mediated-disposition
analyses) · `unresolved_items` · `qualifying_direct_evidence_context_ids` ·
`audit_observation_id`. **Mandatory search = search-completion axes, not evidence
prerequisites and not grading axes** — a component *searched / exhausted with
zero qualifying records* still counts complete; it exists only so the Module
cannot find one quantitation, stop searching the other axes, and cherry-pick a
Direction. **Exactly ONE qualifying context set** —
`qualifying_direct_evidence_context_ids` (the UNION of the single-string
`sink_exposure_context_id` of every observation classified qualifying
`DIRECT`-rung). **There is deliberately NO `qualifying_indirect_evidence_context_ids`
set** (a sheddase-substrate / secreted-isoform / quantitation observation does
not inherently carry a sink-exposure context; `observation_id` / source
provenance suffices for IS inventory audit). The `SEARCH_COMPLETION_AUDIT`
observation carries a structured snapshot of this record locking the qualifying
context set; the snapshot fields are exact-reuse parity keys and a drift /
missing / dedup-lost snapshot, or a drift in the qualifying context set, is a
HARD run-level integrity failure in PR E16.
