# Ubuntu miniPC 性能评估交接

## 目标

对负责人新装的 Ubuntu miniPC 做一次短时、可控的本机性能评估，并据此说明适合的任务级别。重点查看 CPU、内存、存储和 GPU 能力；性能数字只代表本机合成基准，不外推为应用 SLA。

## 执行范围

- 读取 CPU 型号/拓扑、内存与 swap、根盘和磁盘型号/空间、GPU/加速设备、系统负载与温度（若系统已有传感器工具）。
- 不安装软件、不升级软件、不改系统/网络/防火墙配置、不重启、不跑外网测速。
- CPU：使用系统自带 Python 标准库做单 worker 与多 worker 短测，合计 CPU 负载时间目标不超过约 60 秒；报告吞吐量和各阶段时长。
- 内存：临时申请并触碰至多 2 GiB，之后立即释放；若可用内存不足 4 GiB、存在明显 swap 压力或系统负载异常则跳过。
- 磁盘：确认 `/tmp` 所在分区至少有 2 GiB 可用后，写入并同步一个不超过 256 MiB 的临时文件，再顺序读取，完成后删除；不测试系统盘之外的挂载点。
- 运行中若 SSH 变慢、系统开始 swap、温度工具显示超过 85°C、磁盘空间低于门槛或出现错误，立即停止并清理临时文件。
- 结果只写入 PR 的脱敏摘要；不保存完整主机输出、账号、地址、证书或个人文件。

## 数据解释

基准测试用于比较 CPU 单线程与并行吞吐、内存余量和本地顺序 I/O。任务分级还结合检测到的 GPU、CPU、内存和磁盘容量：常驻轻量服务、开发/自动化、小型本地模型推理，以及不适合该设备的训练或大型推理。没有专用 AI 加速器时，不会仅凭 CPU 基准宣称具备高性能模型能力。
