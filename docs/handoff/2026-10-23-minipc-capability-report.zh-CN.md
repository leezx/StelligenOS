# Ubuntu miniPC 性能与任务能力报告

**测试日期：** 2026-10-23
**设备：** Ubuntu miniPC（测试时状态）
**原始评估记录：** [StelligenOS PR #149](https://github.com/leezx/StelligenOS/pull/149)

## 快速结论

这台机器适合做**常驻轻量服务、私人助手的任务编排、浏览器自动化、脚本和轻量开发**，也能承担少量并行 CPU 工作。它是低功耗 CPU 主机，带 Intel 集成显卡和 14 GiB 内存；不要把它当作大型模型训练、高并发推理或 GPU 计算服务器。

| 任务 | 判断 | 依据与边界 |
|---|---|---|
| 轻量服务、定时任务、个人自动化 | 适合 | 8 核/8 线程、14 GiB RAM；需按具体服务的常驻内存量留余量 |
| 浏览器自动化、少量网页/邮件操作 | 适合，控制并发 | 资源级别适合轻量自动化；本次没有单独压测浏览器或邮件应用 |
| 脚本、常规轻量开发、少量并行 CPU 工作 | 适合 | SHA-256 合成测试随 worker 数增加有并行吞吐；不代表所有工作负载都按同样比例加速 |
| 本地小型量化模型推理 | 仅建议试验 | CPU-only 场景；模型速度、上下文长度、内存占用和可用并发都未测，须按具体模型实测 |
| 大型模型训练、高并发模型服务、GPU 密集计算 | 不适合 | 未发现独立 NVIDIA GPU/显存；集成显卡没有经过计算加速测试 |
| 需要已知高速 NVMe/USB 顺序读写的工作 | 暂无结论 | 本次未做物理盘测速，不能从容量或 `/tmp` 表现推断磁盘速度 |

## 设备与测试结果

- **CPU：** Intel Core i3-N305，8 核/8 线程。
- **内存：** 14 GiB。256 MiB 页读写校验通过；约 9.86 百万次 4 KiB 页读/写操作每秒。该数值是本次内存触碰测试的页操作率，**不是 DRAM 带宽**。测试前后 swap 和 OOM 计数没有增加。
- **CPU 短测：** 固定 1 MiB 数据块的 SHA-256 合成测试，1/2/4/8 worker 分别为 **2,335.5 / 4,560.5 / 8,158.5 / 14,350 MiB/s**。8 worker 约为单 worker 的 6.1 倍。该结果只描述 SHA-256 负载，不是通用 CPU 跑分或应用 SLA。
- **图形：** Intel UHD 集成显卡；没有独立 NVIDIA GPU/VRAM 的证据。本次没有测图形、视频编码或 GPU 运算。
- **存储：** 512 GB 级 NVMe（型号报告 JUMPER 512G）；根 ext4 分区约 233 GiB，测试时约 213 GiB 可用。另有约 238.5 GiB USB 磁盘，未测试。`/tmp` 是 tmpfs，与根盘不同，因此物理盘 I/O 测试按方案跳过。
- **温度限制：** 测试期间的温度采集没有正确跟随 sysfs 链接，峰值未知。测试后读数最高 42°C；不能据此断言测试峰值也是 42°C。

## 实际使用建议

1. 把它用于需要持续在线的轻量任务：自动化脚本、个人助手调度、少量后台服务和远程开发。
2. 浏览器/邮件自动化先从少量并发开始；本次没测应用本身的性能，多个浏览器实例可能首先受内存限制。
3. 本地模型先选小型量化模型并单独记录首 token 延迟、生成速度、峰值 RAM、swap 和并发数。**目前没有经本机实测支持的模型参数量上限**，不据此承诺具体模型大小或速度。
4. 磁盘读写性能、长时间持续负载温度、GPU 加速和真实工作流吞吐都尚未测量。需要这些结论时应另做有上限、可复现的专项测试。
